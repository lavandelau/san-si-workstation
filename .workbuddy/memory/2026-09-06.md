## 可复用：跨项目移植单文件 HTML 功能的套路
1. 确认目标文件有依赖函数（fgSndMatch / speakEN / state.progress.english 等）。
2. 源站写好并测通后，用 Python 脚本按「注释 banner 锚点」抽取新代码块，避免手工复制漏改。
3. 目标仓库先确认 `git status` 干净，改完可 `git checkout --` 回滚。
4. 用 vm + DOM 桩对目标文件单独跑一遍功能断言（同一套 stub 换个 argv 路径即可）。
